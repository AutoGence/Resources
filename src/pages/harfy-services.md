# HARFY Software and System Services

## Software services for robotic control applications

Autogence, L.L.C. provides services under the HARFY name for customers developing and operating robotic control applications:

- Computer programming
- Updating of computer software
- Computer software design
- Consultancy in the design and development of computer hardware
- Maintenance of computer software
- Computer system design
- Development of computer platforms

Our computer programming work includes development of joystick-control software for robotic systems.

Our hardware-design consultancy covers compute-unit and control-board design for robotic systems.
